# EverySearch plugin

Use EverySearch MCP for web search and page retrieval. Select a live search mechanism, preserve original source links and make retrieval gaps explicit.

This package contains only `everysearch`. It is a skills-only plugin: configure the approved EveryInfra service connection in the host before using it. It does not install other skills, register a new MCP server or broaden API permissions.

Relevant retrieved material with usable source URLs and a clear statement of scope and freshness. Empty results mean the retrieval found nothing within its scope, not that the requested fact is false.

- Available search, semantic, academic, forum or page-reading mechanisms must be discovered; none is guaranteed by a static README.
- Do not relabel repeated keyword searches as an independent cross-check.
- A page may be inaccessible or a result stale; disclose that instead of filling the gap with an invented answer.

Repository documentation and installation guidance accompany the source checkout. Current API documentation: https://api.everyinfra.com/docs
